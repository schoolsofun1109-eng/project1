================================================================================
ROOT CAUSES ADDRESSED
================================================================================

Bug 1: Copy-paste error
  - Weight tile descriptor used wrong size variable (X_tile_size instead of W_tile_size)
  - Impact: Incorrect SRAM allocation for rectangular matrices

Bug 2: Over-generalized workaround
  - Stride computation special-cased N=1 but broke general case
  - Impact: Incorrect DRAM offset calculations in nested split loops

Both bugs specifically affected rectangular matrices (M != N) because:
  - Square matrices: TILE_M = TILE_N = 64, bug masked by symmetry
  - Rectangular matrices: Different tile sizes expose mismatch
  - Split iterations: Nested loops expose stride calculation errors
