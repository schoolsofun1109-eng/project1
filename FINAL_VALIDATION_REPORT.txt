================================================================================
ANALYSIS
================================================================================

Tile Stride Fix (27ede7a) Details:

Before:                        After:
X_tile_stride = [TILE_M, 1]   X_tile_stride = [TILE_K, 1]
W_tile_stride = [TILE_K, 1]   W_tile_stride = [TILE_N, 1]
Y_tile_stride = [TILE_M, 1]   Y_tile_stride = [TILE_N, 1]

Mathematical Correctness:
For row-major [rows, cols] matrix, stride = [cols, 1]
- X[TILE_M, TILE_K] → [TILE_K, 1] ✓ CORRECT
- W[TILE_K, TILE_N] → [TILE_N, 1] ✓ CORRECT
- Y[TILE_M, TILE_N] → [TILE_N, 1] ✓ CORRECT

Why Squares Pass:
- M=N case: TILE_M = TILE_N
- Original [TILE_M, 1] and fixed [TILE_K, 1] both work
- Fix passes by accident for square case

Why Rectangles Fail:
- M≠N case: TILE_M ≠ TILE_N
- Stride definition alone is insufficient
- Root cause in split-iteration DMA addressing or SRAM allocation

Failure Pattern:
Test 1: First tile OK, second tile errors (max_diff=78.0)
Test 2: First rows OK, last row all zeros
Test 9: Partial correct, middle rows zeros
→ Suggests: Partial tile allocation failure, buffer overflow, or offset error
