KEY FINDINGS

1. BUFFER COLLISION FIX (commit 66d0acd)
   Status: ✓ Applied, ✗ Insufficient
   
   The fix changes buffer naming:
   - OLD: "W_spad" (all N-split iterations use same name)
   - NEW: "W_0_spad", "W_1_spad", ... (unique per iteration)
   
   This prevents buffer NAME aliasing but does NOT fix deeper issues:
   - N-split iteration coordination is still broken
   - Output buffer accumulation across iterations fails
   - Weight tile loading for splits is incomplete

2. ERROR PATTERNS
   
   Pattern A (Test 1): "Correct edges, wrong middle"
   - First/last columns correct, middle columns wrong
   - Indicates: Weight tiles mismapped in N-split iterations
   - Only first and last weight tiles loaded correctly

   Pattern B (Tests 2,5,9): "Zero rows"
   - Last rows contain zeros instead of computed values
   - Indicates: Output buffer not accumulating across iterations
   - Partial output from N-split accumulation

   Pattern C (Tests 3,4,10): "Scattered errors"
   - Errors distributed across output matrix
   - Indicates: Buffer overwrite or iteration ordering issues
   - Multiple N-split coordination problems

3. SQUARE MATRIX SUCCESS
   - All N×N cases pass with 0 error

   - Proves bug is SPECIFIC to multi-iteration N-split handling

================================================================================
ROOT CAUSE ANALYSIS
================================================================================

The rectangular matmul bug has TWO distinct layers:

LAYER 1: BUFFER NAME COLLISION (FIXED)
✓ Commit 66d0acd correctly ensures unique buffer names
✓ No more SRAM aliasing between different iterations

LAYER 2: N-SPLIT ITERATION COORDINATION (NOT FIXED)
✗ OMEM accumulation broken across iterations
✗ Weight tile addressing broken for N-split
✗ DMA loop sequencing broken for rectangular tiles
✗ MLIR variable linking possibly broken between iterations

EVIDENCE:
- Error patterns are SELECTIVE (some elements right, some wrong)
- Not uniform garbage (which would indicate buffer collision alone)
- Buffer naming fix doesn't reduce error magnitudes
- Square matrices (no N-split) work perfectly
- Rectangular matrices (N-split required) all fail

CONCLUSION:
The buffer naming fix was necessary but NOT sufficient.
Additional architectural fixes required for N-split coordination.
